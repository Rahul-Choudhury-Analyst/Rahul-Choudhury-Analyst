### 🚀 Featured Portfolio Project

#### 🔍 [Broker Abuse & Fraud Detection Engine (MT5 Risk Analytics)](https://github.com/Rahul-Choudhury-Analyst/Broker-Abuse-Detection)
*End-to-end risk analytics pipeline engineered with Python, PostgreSQL, and Excel to identify toxic trading behavior.*
* **Synthetic Data & EDA:** Simulated 2,000 MT5 trades across 50 client accounts (`XAU/USD`, `EUR/USD`, `GBP/JPY`, `BTC/USD`) with a 15% injected IB Churning anomaly and automated statistical profiling via `Sweetviz`.

* **Interactive Risk Dashboard:** Delivered a cleaned Excel dashboard featuring Pivot Charts, `Symbol` & `Bonus_Utilized` Slicers, and dynamic `XLOOKUP`/`FILTER` suspect lookup views.
